# 🍽️ Foodie's Choice

A simple and responsive **Food Recipe Explorer** web app that lets users browse meals by category, view full recipe details, and watch YouTube cooking tutorials — all in a clean and modern UI.

---

## 🚀 Live Demo
👉 [View Project Here](https://movies-project0-gm69.vercel.app/)

---

## ✨ Features
- 🏷️ **Select Category:** Choose from Beef, Chicken, Seafood, Vegan, etc.  
- 🖼️ **Meal Cards:** Displays meals with images and names.  
- 📄 **Meal Details Modal:** Shows ingredients, cooking instructions, and a YouTube tutorial link.  
- 📱 **Responsive UI:** Works on desktop and mobile screens.  
- ⚡ **Dynamic Data:** Uses [TheMealDB API](https://www.themealdb.com/api.php) to fetch meal data in real time.  

---

## 🛠️ Built With
- 🌐 **HTML5**
- 🎨 **CSS3 (Custom variables, Flexbox)**
- ⚡ **Vanilla JavaScript (ES6+)**
- 🍲 **TheMealDB API**
